# Spectreasy

Spectreasy (or OpenGate) is temporarily unavailable while development is paused for manuscript submission.

## Feature overview

Spectreasy is an R-based spectral flow-cytometry workflow for:

- reviewing single-color controls and building spectral reference matrices
- AutoSpectral, OLS, NNLS, WLS, and robust WLS unmixing
- interactive control gating and gate reuse
- autofluorescence and background handling for cell and bead controls
- modular quality-control reports and pairwise spectral diagnostics
- flowSet and SingleCellExperiment workflows
